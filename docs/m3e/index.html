m3e-canvas 设计画布

这是设计的来源，不是截图 —— 一份可交互、可继续编辑的真实画布。

在浏览器里打开这份设计

链接里带着整份画布文档（#docz=，deflate-raw + base64url）。打开后能看到 9 个并排的手机画布、68 个组件组 / 77 个组件、真实的 Material 3 Expressive 组件库、 屏幕之间的跳转箭头。按 P 进入预览模式，可以点着把这个应用的流程走一遍。

画布数据只存在你自己的浏览器里（localStorage），不会上传。链接比较长（约 9.5KB），完整内容见 docs/m3e/kaze-redesign.share.txt；右边按钮直接从本地文件读取，所以打开的一定是这份设计。

打开设计画布 ↗ 查看画布 JSON

这份画布是怎么来的

m3e-canvas 是纯前端工具，正常用法是在浏览器里拖拽。拖拽的结果没法版本化、也没法复核， 所以这里改成直接驱动它的引擎：把仓库 clone 下来，用脚本构造它的画布文档，调用它自己的 lib/prompt.ts 导出设计稿，再用它 lib/share.ts 的格式生成分享链接。

生成脚本还带几何自检（不越界、不重叠）—— m3e-canvas 会把「两组重叠」读作「叠放」，普通堆叠必须不重叠。这个检查一开始抓出了 39 处版面错误。

查看生成脚本 tools/gen.mts 查看 docs/m3e/README.md
